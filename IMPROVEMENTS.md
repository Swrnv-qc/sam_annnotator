# Future Improvements & Roadmap

This document outlines potential enhancements, optimizations, and features for the SAM 2 Auto-Annotator to evolve from a prototype into a production-grade labeling tool.

## 1. UI/UX Enhancements
- **Zoom & Pan:** Support for high-resolution images (4K+) by implementing a "Google Maps" style zoom/pan canvas to allow pixel-perfect vertex placement on small objects.
- **Class Management:**
    - A dedicated sidebar for managing classes (add/rename/delete).
    - Color-coding for different classes in the polygon overlay.
- **Dark Mode:** A toggle for a dark theme to reduce eye strain during long annotation sessions.
- **Customizable Shortcuts:** Allow users to remap keys (e.g., changing 'Enter' to 'Space' for Run SAM).
- **Brush/Eraser Tool:** A manual mask refinement tool (brush/eraser) for pixel-level corrections that are difficult to achieve with polygon vertices.

## 2. AI & Inference Optimization
- **SAM 2 Video Tracking:** Leverage SAM 2's temporal consistency to propagate masks across video frames automatically.
- **Auto-Prompting:** Integrate a standard YOLO model (e.g., YOLOv11) to generate initial bounding box "proposals" that SAM 2 then converts into high-quality polygons.
- **Model Quantization:** Support for `FP16`, `INT8`, or `ONNX` exported models to significantly reduce VRAM usage and increase inference speed on lower-end hardware.
- **Tiled Inference:** For extremely large images, implement tiled processing to stay within VRAM limits without downscaling.

## 3. Dataset Management
- **Label Browser:** An interface to load, view, and edit existing YOLO `.txt` labels from the `labels/` folder.
- **Format Converters:** Export functionality for other popular formats like COCO (JSON), Pascal VOC (XML), or TFRecord.
- **Analytics Dashboard:** Visualization of dataset statistics (e.g., class distribution, average object size, annotation progress).
- **Cloud Integration:** Support for loading images from and saving labels to S3, GCS, or Azure Blob Storage.

## 4. Technical Stability & Performance
- **Asynchronous Processing:** Move inference to a background worker (e.g., Celery or a dedicated process) to prevent the FastAPI event loop from blocking during heavy computations.
- **WebSockets:** Use WebSockets for real-time progress updates during batch processing or model loading.
- **Electron Wrapper:** Package the application as a standalone desktop app for a more native feel and easier file system access.

## 5. Collaboration Features
- **Multi-user Support:** Basic authentication and session management to allow multiple annotators to work on the same server.
- **Review Workflow:** A "Quality Control" mode where a senior annotator can approve or reject labels generated by others or the AI.
